## prisma flow

you write your prisma schema in your prisma folder which is auto generated by the prisma init process for your project.
Then you specify the client generator configs in that schema file like where to put the generated output and all.
Then the client gets generated in specified folder as client.ts. You need to import from that client ts file.

## prisma commands

to initialise the project
npx prisma init --datasource-provider postgresql --output ../generated/prisma

to connect to db and for first migration
npx prisma migrate dev --name init
you need to need to run this command only when you write your schema file for the first time or when you make changes in it

to generate the client
npx prisma generate

to open prisma studio in browser
npx prisma studio

## System Design

HLD

A high-level design answers questions like:

What are the major components?
What is each component responsible for?
How do they communicate?
Where does important state live?
What are the important system-wide tradeoffs?

LLD

A low-level design answers questions such as:

What exact request fields are sent?
Which route, controller, middleware, and RPC method handle them?
How is the request validated and serialized?
What does the response contain?
What errors can occur?

For system design, A useful study order is:

Requirements and constraints: scale, latency, durability, availability.
HLD: components, data flow, storage choices, and major tradeoffs.
Critical LLD details: protocols, data structures, partitioning, caching, replication, and failure handling.
Tradeoffs and alternatives: what the design gains and what it makes harder.

Topics from Computer Networks required to better understand system design:

HTTP request/response, headers, status codes, and keep-alive
DNS, IP addresses, ports, and TCP
TLS and certificates
Proxies, load balancers, and CDNs
Latency, bandwidth, timeouts, retries, and connection failures

“Scaling” is broad too. At HLD, describe the scaling approach and its tradeoffs; at LLD, detail the mechanisms that implement it.

## PostgreSQL

to run the postgres service, open terminal as admin and run
net start postgresql-x64-18

then to be connected as the superuser, run
psql -U postgres
it will prompt for password

postgres= commands
\l to list dbs
\c database_name to connect to db
\dt to list its table
you can always check current state of data in db to know that if your updates are migrated or not.

\d table_name to see the exact structure of the table

after getting into your desired database, you can write raw sql queries.
