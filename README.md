NexusMesh is a distributed simulation platform modeling community Wi-Fi infrastructure. It integrates a high-performance C++ service leveraging Quadtree indexing and custom Dijkstra routing algorithm to compute optimal data routing paths between network nodes in real time. The system orchestrates multiple services using Node.js, React.js, gRPC, and Protocol Buffers for fast, low-latency inter-service communication. For data management, it employs a robust multi-database strategy combining MongoDB, PostgreSQL with Prisma ORM. Additionally, NexusMesh incorporates a Solidity smart contract deployed on a Hardhat Ethereum testnet, bridging real-time network simulation with decentralized node management and logging capabilities.
